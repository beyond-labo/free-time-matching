# 原因調査担当への入力

[kiro-debug](../../kiro-debug/SKILL.md) を読んで適用する。担当は原因調査と修正案の提示であり、明示的に割り当てられた場合だけファイルを変更する。他者の変更を戻さない。

## 親が渡す情報

- 元の症状、実行コマンド、エラー出力、環境・依存版
- タスク本文、要件・設計のパスと元の節番号、責務境界
- 作業開始点と既存変更、今回の変更差分
- レビュー指摘、既に試した操作と結果、関連する実装上の知見

## 返す情報

`kiro-debug` 本体の `Debug Report` 形式で、確認済みの原因と仮説の区別、所有箇所、最小の修正または次の識別実験、検証方法、仕様同期と承認の要否を返す。
