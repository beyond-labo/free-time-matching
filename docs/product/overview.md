# 製品の範囲

ひまっち（仮）は、暇時間と募集を扱う iOS アプリと Backend から構成します。
添付には認証、ユーザー、友人関係、暇時間、募集、通知、アカウント削除の機能領域が示されています。
対象利用者の詳細や各画面の受け入れ条件は、今後の要件定義で確定します。

| 領域 | Backend の実装時の配置（src 配下） | 現時点で読み取れる責務 |
| --- | --- | --- |
| 認証 | `src/auth/` | 認証に関する処理 |
| ユーザー | `src/users/` | ユーザー情報 |
| 友人関係 | `src/friendships/` | ユーザー間の関係 |
| 暇時間 | `src/availability/` | 暇時間の登録と参照 |
| 募集 | `src/hostings/` | 募集に関する処理 |
| 通知 | `src/notifications/` | 通知の作成と送信 |
| アカウント削除 | `src/account-deletion/` | アカウント削除の調整 |

## 要件として未確定の事項

- 認証プロバイダー、ログイン方法、認可ルール。
- 友人関係の成立条件、招待方法、ブロックの扱い。
- 暇時間の粒度、タイムゾーン、公開範囲。
- 募集の状態遷移、参加条件、期限。
- 通知チャネル、再送条件、配信の重複対策。
- アカウント削除の対象データ、保持期間、削除完了条件。
- 最低対応 iOS、公開時期、運用規模。

添付中の `freeMask`、`shareMask`、`private`、`share_on_hosting` は内部表現と公開表現を分離する説明例です。
これらの保存形式や値を今回の業務仕様として固定しません。
「4週間程度の初版開発」は方式選定の背景として提示されたもので、確定した納期ではありません。
