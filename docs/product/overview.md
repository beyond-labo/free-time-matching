# 製品の範囲

ひまっち（仮）は、暇時間を基本非公開で預け、友達からの募集に参加OKした時間だけを共有して予定を成立させるアプリです。
初版のiOSは日本向け・18歳以上・既知の友達5〜20人による招待利用を想定し、15分単位の暇時間、募集、回答、確定、安全機能、アカウント削除までを扱います。
Backendは公開契約・認可・複数ユーザー整合性・通知・実削除を所有します。初版ではSign in with AppleをSupabase Authへ接続し、ニックネーム＋プリセットアイコンのプロフィール、期限付き招待コードと相互承認による友達関係、アカウント削除を実 Backend 境界として実装します。暇時間の本人限定登録・参照・削除も実 Backend 境界へ接続します。最初の内部TestFlightはstaging Supabaseとstaging APIへ接続します。募集の画面と状態遷移は引き続きPrototype Adapterであり、実 Backend の複数ユーザー安全性を実証したものとは扱いません。

| 領域 | Backend の実装時の配置（src 配下） | 現時点で読み取れる責務 |
| --- | --- | --- |
| 認証 | `src/Auth/` | 認証に関する処理 |
| ユーザー | `src/User/` | ユーザー情報 |
| 友人関係 | `src/Friendship/` | ユーザー間の関係 |
| 暇時間 | `src/Availability/` | 暇時間の登録と参照 |
| 募集 | `src/Hosting/` | 募集に関する処理 |
| 通知 | `src/Notification/` | 通知の作成と送信 |
| アカウント削除 | `src/AccountDeletion/` | アカウント削除の調整 |

## 初版で確定した製品契約

- 認証はSign in with Appleを使い、独自パスワードを持たない。
- 友達は期限付き招待コード、申請、相手の承認で成立する。全ユーザー検索と連絡先同期は行わない。
- 暇時間は15分単位、今後14日、初期2時間とし、新規枠の共有設定は「参加OKするまで非公開」に戻す。
- 暇登録、募集時共有、参加OK、予定確定は別の意思表示として扱う。
- ホストには非公開ユーザーへの配信有無・人数・辞退・未登録状況を返さない。
- 募集は候補期間、必要時間、開催形態、定型カテゴリ、友達を指定し、募集後の条件変更は取消と再作成で行う。
- Pushは補助であり、拒否してもアプリ内受信箱から回答・確定できる。
- 通報、ブロック、運営の是正、アプリ内アカウント削除を初版の完成条件に含める。
- iOSは17以降、SwiftUI/TCA、Swift Testingを使用し、iOSテストではXCTestを使用しない。

詳細な受け入れ条件は `.kiro/specs/ios-*`、依存順は `.kiro/steering/roadmap.md` を正本とします。

## 引き続き未確定・外部準備が必要な事項

- 募集 Backend APIの具体的フィールド、暇時間の友達向け共有・募集照合、Push配信、削除ジョブ。
- 実Bundle ID、Apple Team、App Store Connectのアプリレコードと審査用アクセス方式。
- 公開する利用規約・プライバシーポリシー・問い合わせURL、運営担当者と通報対応手順。
- App Store年齢レーティングとPrivacy Labelの最終申告。

添付中の `freeMask`、`shareMask`、`private`、`share_on_hosting` は内部表現と公開表現を分離する説明例です。
これらの保存形式や値を今回の業務仕様として固定しません。
「4週間程度の初版開発」は方式選定の背景として提示されたもので、確定した納期ではありません。
