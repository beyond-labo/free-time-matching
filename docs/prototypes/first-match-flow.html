動線プロトタイプ · iOS 初版

アイマノ はじめてのお誘い

起動してから「友達が参加OKする」までを、あなたと友達（田中さん）の2台で操作できます。暇は非公開のまま、選んだ友達にお誘いを送り、相手が参加できる時間を返す、という現行仕様の契約は変えていません。

開始する場面
あなた（ひいらぎ）
田中さん（友達）

現行アプリとの差分

いまの分かりにくさ

  • ホームの主役が日/週の15分グリッドで、何をすれば友達と遊べるのかが書かれていない。
  • 友達0人でも「友達を誘う」が押せて、時間選択モードに入ってから招待先がいないことに気づく。
  • 誘う画面に開催形態・エリア・カテゴリ・暇のカテゴリ・暇の公開設定・統合確認が並び、内部の概念がそのまま見えている。
  • 受け取った側はベルからシートを開き、±ボタンで開始と終了を15分ずつ動かし、「この範囲で回答」→「参加OK」の2段階で送る。ベルに未読バッジがない。
  • 参加OKが届いても、ホームの「募集中 1件」バナーの奥にしか出ない。
  • 「デモデータで試す」がプロフィール保存で失敗し、体験に入れない（Prototype シナリオが未接続）。

このプロトでの方針

  • 最初の目標を「はじめてのお誘い」の3ステップとしてホーム上部に出し、次にやることを1つに絞る。
  • 時間はよく使う候補（今夜・明日の夜・週末・自分の暇）をワンタップで選び、細かい調整は日付と時刻の選択で行う。
  • 入力は「いつ・だれと・会い方」の3つだけにし、内容は任意、暇の公開設定は安全な既定値（非公開）にして画面から外す。
  • 届いたお誘いはホーム最上部に出し、「全部・前半・後半・時間を指定」から選んで1回で返事を送る。初期選択はしない。
  • 参加OKはホームのお誘いカードに時間の帯で表示し、複数人なら全員そろう時間を示す。
  • カレンダー表示は残し、「カレンダーで見る」から開く二次画面にする。

仕様への影響と未決事項

  • ios-hosting 1.1：時間軸のタップ・ドラッグに加え、時間候補からの開始を追加する。
  • ios-hosting 2.2：表示文言を「お誘い」に統一するなら要件の文言を変える。現行は「募集を開始しました…」。
  • ios-hosting / ios-availability：募集時の暇の属性と公開設定を既定値にし、重なる暇の属性が違うときだけ確認を出す。
  • ios-app-integration：ホーム投影の構成（はじめての手順、届いたお誘い、あなたのお誘い、暇）と、DEBUG デモでの Prototype シナリオ接続。
  • 未決：会い方（オンライン/会う）を毎回必須にするか、前回値を既定にするか。プロトでは必須にしている。
  • 未決：「前半・後半」の分け方。プロトでは2時間以上の候補を15分単位で半分に分けている。
