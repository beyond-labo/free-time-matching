# ひまっち（仮）

iOS と Backend を独立したアプリケーションとして管理するモノレポです。
Backend が公開 API 契約を所有し、iOS は OpenAPI から生成したクライアントを利用します。

## ドキュメント

[ドキュメント一覧](docs/README.md)から、製品の範囲、技術方針、パッケージ構成、API 契約、開発と運用の手順を参照できます。

## 現在の状態

添付された構成案に基づくディレクトリと設定の土台を作成しています。
業務機能、HTTP サーバー、OpenAPI 生成、iOS のビルド設定、インフラ、デプロイは未実装です。
空のディレクトリは `.gitkeep` で保持しています。
`Himatch.xcodeproj` は配置場所のみであり、Xcode で開けるプロジェクトではありません。

## 構成の確認

Node.js と pnpm が利用できる環境で実行します。

```sh
make bootstrap
make verify
pnpm --filter @himatch/backend verify
```

現在の検証は構成と JSON の検証です。
アプリのテストやビルドが成功したことを意味しません。
ランタイムとツールの採用バージョンは、実装開始時に固定します。
